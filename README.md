# homebrew-tap

My personal Homebrew tap.

## Available formulas

- **[anu](https://github.com/aadarwal/anu)** — a research agent harness: AI agents as first-class terminal panes, scaled into isolated swarms and checked against one another. The manifesto lives at [michelangelo.sh](https://michelangelo.sh). (Supersedes `omacmux`.)
- **[helium-sync](https://github.com/aadarwal/helium-sync)** — sync Helium browser bookmarks and saved tab groups across Macs via your private git repo.
- **[omacmux](https://github.com/aadarwal/omacmux)** — *(legacy; renamed to [anu](https://github.com/aadarwal/anu))* agent-first IDE built on tmux.

## Install

```bash
brew install aadarwal/tap/<formula-name>
```

For example:

```bash
brew install aadarwal/tap/anu
anu init
```

`brew tap aadarwal/tap` is implicit on first install.
